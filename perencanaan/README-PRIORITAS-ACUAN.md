# Panduan folder perencanaan

Folder ini adalah lokasi kerja kanonis untuk perencanaan produk. Mulai pekerjaan lanjutan dengan membaca `PRD-Sistem-Pendataan-KDKMP-Lahat.md`, lalu baca seluruh `LIST-GRUP-ITEM-RENCANA-PENILAIAN-REVISI.md`.

## Urutan kewenangan

1. Keputusan langsung terbaru pemilik proyek.
2. `LIST-GRUP-ITEM-RENCANA-PENILAIAN-REVISI.md` untuk daftar Form B.
3. `STRUKTUR-FORM-PENDATAAN-BARU.docx` untuk tambahan yang tidak bertentangan.
4. Source runtime dan migration untuk perilaku yang saat ini terimplementasi; source bukan persetujuan produk dan bukan bukti migration remote diterapkan.
5. Dokumen lama dalam folder ini hanya sebagai konteks historis jika bertentangan.

## Catatan salinan folder

Berkas planning dipertahankan di folder lama `planing/` sebagai salinan sumber. Pemindahan folder tersebut gagal karena Windows melaporkan ada berkas yang sedang digunakan. Berkas-berkasnya telah disalin ke sini, dan PRD baru dibuat di folder ini. Untuk perubahan berikutnya, edit salinan di `perencanaan/`; jangan mengedit dua salinan berbeda. Setelah dokumen yang mengunci folder lama ditutup, folder lama dapat dirapikan terpisah dengan memastikan salinan ini lengkap terlebih dahulu.

## Catatan versi lama

- PRD terdahulu disimpan di `arsip/PRD-Sistem-Pendataan-KDKMP-Lahat-V1-ARSIP.md`.
- `STRUKTUR-FORM-PENDATAAN.md` menyebut Status sumber Permanen/Sementara; itu tidak berlaku lagi.
- `PROMPT-LOGIKA-KONDISI-ITEM.md` dan `STRUKTUR-FORM-PENDATAAN-BARU.docx` memuat beberapa detail interaksi yang harus tunduk pada aturan terbaru di PRD dan daftar utama.
- `UI-UX-*.html` adalah prototipe lama; pemilik proyek meminta AI berikutnya menentukan desain baru.
